Meu Primeiro Dashboard em Excel AI

📊 Sobre o projeto

Este projeto apresenta meu primeiro dashboard desenvolvido com Excel e Inteligência Artificial, criado para organizar, analisar e visualizar dados de despesas pessoais.

🚀 Funcionalidades

* 📥 Importação de arquivos Excel
* 📊 Gráficos de despesas
* 📈 Estatísticas e indicadores
* 📋 Visualização dos dados em tabela
* 📄 Exportação para CSV
* 📝 Exportação para Word
* 📕 Exportação para PDF

🎯 Objetivo

Aprender a utilizar Excel, análise de dados e Inteligência Artificial para transformar dados em informações visualmente organizadas e fáceis de compreender.

🛠️ Tecnologias

* Microsoft Excel
* Inteligência Artificial
* HTML
* JavaScript
* CSS
